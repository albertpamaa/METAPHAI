世界データの情報源と方法

MetaphAIがこのセクションのデータを取得、検証、変換する方法。

統計情報源

初回版は世界銀行が公開する World Development Indicators (WDI) のみを使用します。各指標について公式メタデータに記載された情報源組織も保持します。

ライセンスと表示

カタログでは WDI は CC BY 4.0 とされています。元の提供者の権利が別途適用される場合があります。MetaphAI は世界銀行ではなく、世界銀行は本サービスに参加、後援、承認、推奨していません。ロゴも使用しません。

取得と更新

週次処理が公式 API を照会し、応答を検証してローカルファイルを生成します。取得日はファイルを得た日、最新年は観測年であり、両者は異なる場合があります。

国、欠損値、順位

API の区分に基づき世界、地域、所得層などの集計を除外します。null をゼロにせず補間もしません。共通年は指標の通常の最大年次カバレッジの70%以上が必要です。変化には両端値が必要で、割合指標の差はパーセントポイントです。

MetaphAIの処理

国と集計を分類し、nullを除外し、並べ替え、中央値、順位、変化を計算します。丸めは表示時だけで、詳細表とCSVは受信値と機械可読形式を保持します。因果説明や欠損補完は行いません。

プライバシー

本セクションは集計された地域データを使用し、個人の検索、位置、氏名、メールを要求・保存しません。

指標

出典：World Bank — World Development Indicators。MetaphAI はランキングから欠損値と集計値を除外し、並べ替えと変化の計算を行い、表示時のみ丸めます。世界銀行は本サービスに関与せず、推奨もしていません。
