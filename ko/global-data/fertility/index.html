여성 1명당 출생아 수의 기간 지표를 비교합니다.

측정 내용

합계출산율은 관측 연도의 연령별 출산율을 합한 기간 지표입니다. 가상의 여성이 가임기 내내 같은 출산율을 경험할 때의 출생아 수를 뜻하며 실제 여성이나 코호트의 최종 자녀 수가 아닙니다.

해석 방법

1.9는 해당 기간의 종합 패턴입니다. 인구 대체는 사망률, 성별 구성, 이주에도 좌우됩니다.
