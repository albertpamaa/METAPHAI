全球数据来源与方法

MetaphAI 如何获取、验证和处理本节数据。

统计来源

首版仅使用世界银行发布的 World Development Indicators (WDI)。每项指标也保留官方元数据列出的来源机构。

许可与署名

目录将 WDI 标为采用 CC BY 4.0。原始提供方的其他权利仍可能适用。MetaphAI 不是世界银行；世界银行不参与、不赞助、不批准或认可本服务，我们也不使用其标志。

下载与更新

每周流程查询官方 API、验证响应并生成本地文件。下载日期表示取得文件的时间，最新可用年份表示观测年份，两者可能不同。

国家、缺失值与排名

依据 API 的分类排除世界、地区、收入组等汇总。空值不会改为零或插值。共同年份必须达到该指标最高常规年度覆盖率的至少 70%。变化必须有两个端点；百分比指标用百分点表示差异。

处理方式

MetaphAI 区分国家与汇总、排除空值、排序并计算中位数、排名和变化，只为显示而舍入。详细表和 CSV 保留收到的数值及机器可读格式，不添加因果解释或填补缺口。

隐私

本节使用汇总地域数据，不请求或存储个人搜索、位置、姓名或电子邮件。
