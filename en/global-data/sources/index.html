Sources and methodology

How MetaphAI obtains, validates and transforms the data shown in this section.

Statistical source

The first release uses only World Development Indicators (WDI), published by the World Bank. Each indicator also retains the source organisation given in its official metadata.

Licence and attribution

The catalogue identifies WDI as public and licensed under Creative Commons Attribution 4.0. This licence permits copying, redistribution and transformation, including commercial use, with attribution and an indication of changes. Rights or conditions from original providers named in a series’ metadata may also apply.

MetaphAI is not the World Bank. The World Bank does not participate in, sponsor, approve or endorse this service. We do not use its logo.

Download and updates

A weekly process queries the official API, validates responses and generates local files. The download date records when the file was obtained; the latest available year records when the observation was made and may be earlier.

Countries and aggregates

Rankings explicitly exclude World, regions and income groups using the API’s own territorial classification. Aggregates remain identified for possible future comparisons but are never presented as countries.

Missing values and rounding

Null values are excluded: they are not converted to zero or interpolated. The interface rounds only for readability; detailed tables and CSV files retain the value received. CSV column names remain stable and numeric values use a locale-independent machine-readable representation.

Rankings and changes

The latest common year must reach at least 70% of the indicator’s highest usual annual coverage. Every country in a ranking belongs to exactly that year. Percentage changes require values at both endpoints; for indicators expressed as percentages, differences are shown in percentage points.

Transformations

MetaphAI classifies countries and aggregates, excludes nulls from visualisations, sorts observations, calculates medians, rankings and changes, and applies visual formatting and rounding. It does not add causal explanations or fill gaps.

Privacy

This section uses aggregated territorial data and does not request or store personal searches, location, name or email.
